## Why This Tool?

Sending money home from Japan? Compare fees, exchange rates, and speed across services like Wise, Revolut, and SBI Remit — plus check if a service is a scam.

## Features

- **Side-by-side comparison** — See fees, rates, and delivery speed for each service
- **Live exchange rates** — Mid-market rates updated in real time
- **Sort by what matters** — Best value, lowest fee, or fastest delivery
- **Built-in scam checker** — Verify if a transfer service is legitimate
- **Multiple currencies** — Compare rates for different destination countries

## How It Works

1. Enter the amount and destination currency
2. Compare services side by side
3. Check the scam status of any service

> **Try it now:** [https://humancronadmin.github.io/money-transfer-japan/](https://humancronadmin.github.io/money-transfer-japan/)

## Data Sources

- Exchange rates: Live mid-market rates
- Service fees: Based on publicly available information from each provider's official website

**Disclaimer:** Fees and rates shown are estimates. Always verify on the provider's official website before sending money.

## Privacy

- All comparisons run **in your browser** — no data is sent to any server
- No cookies, no account required
- Works offline after first visit (PWA)
